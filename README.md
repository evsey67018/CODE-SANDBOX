# Code Sandbox

Однофайловая онлайн-песочница для HTML, CSS, JavaScript, JSON, SVG, XML и Markdown. Весь интерфейс находится в `index.html`: страница, стили и логика. Редактор тёмный, остальной сайт — светлый, в тёплых оранжевых тонах.

Код из вкладок собирается в документ и запускается в `iframe` с атрибутом `sandbox="allow-scripts"`. У фрейма нет доступа к родительской странице. Родительский скрипт не вызывает `eval`.

## Как открыть

- Локально: откройте `index.html` в браузере или запустите любой статический сервер в корне репозитория.
- В интернете: включите GitHub Pages (шаги ниже). Адрес будет вида `https://<пользователь>.github.io/<репозиторий>/`.

На странице `file://` буфер обмена и `localStorage` в части браузеров ограничены. Для черновиков и кнопки «Поделиться» удобнее открыть страницу через локальный сервер или Pages.

## Как пользоваться

Одно окно редактора. Вкладки переключают язык, но не стирают остальные:

`HTML | CSS | JavaScript | JSON | SVG | XML | Markdown`

1. Выберите вкладку и введите код. Tab вставляет два пробела, Enter сохраняет отступ.
2. Предпросмотр обновляется сам через секунду. Кнопка **Запустить** или **Обновить** делает это сразу.
3. Внизу предпросмотра — консоль: `console.log`, предупреждения и ошибки выполнения приходят из фрейма через `postMessage`.
4. **Копировать весь код** кладёт в буфер все семь вкладок: HTML-комментарий, блок `<style>`, блок `<script>`, затем JSON, SVG, XML и Markdown.
5. **Скачать** сохраняет собранный документ как `sandbox-ГГГГ-ММ-ДД.html`.
6. **Форматировать** и **Сжать** обрабатывают текущую вкладку.
7. **На весь экран** открывает предпросмотр поверх страницы. Закрытие — Esc или «Закрыть». У полноэкранного окна своя кнопка «Запустить».
8. **Поделиться** записывает все вкладки в хеш `#code=` (JSON в base64) и копирует ссылку. Старый формат одной строки тоже открывается: стили и скрипты из HTML раскладываются по вкладкам.
9. Черновик сам пишется в `localStorage` под ключом `code_sandbox_draft` (пауза 1 секунда). Ссылка из адреса важнее черновика. **Сбросить черновик** возвращает пример «Привет, мир».
10. **Очистить** спрашивает «Вы уверены?» и стирает все вкладки вместе с предпросмотром.
11. Меню **Примеры** подставляет готовые фрагменты: приветствие, живую кнопку, калькулятор, JSON, SVG и Markdown.
12. Если вставить в HTML документ со `<style>` и `<script>` или цельный CSS, JS, JSON, SVG, XML или Markdown, песочница предложит разложить фрагмент по вкладкам.
13. Над редактором — доли HTML, CSS, JS и текста. На вкладку нельзя записать больше 100 КБ: лишнее не принимается, появляется предупреждение.

В предпросмотре Markdown становится заголовками, списками, жирным, курсивом, кодом и ссылками. JSON только показывается в `<pre>` и не выполняется. Ссылки в Markdown разрешены для `http`, `https` и `mailto`.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Ctrl+Enter или Cmd+Enter | Запустить предпросмотр |
| Ctrl+Shift+C | Копировать весь код |
| Ctrl+S | Скачать HTML (окно сохранения браузера не открывается) |
| Tab | Вставить два пробела или сдвинуть выделенные строки |
| Shift+Tab | Убрать отступ |
| Esc | Закрыть полноэкранный режим или диалог |
| Стрелки влево и вправо на вкладке | Соседний язык |

## GitHub Pages

1. Файл `index.html` должен лежать в корне ветки `main` (так и есть).
2. Откройте репозиторий на GitHub → **Settings** → **Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**.
4. Ветка: `main`. Папка: `/ (root)`. Нажмите **Save**.
5. Через минуту сайт откроется по адресу, который Pages покажет вверху раздела. Обычно это `https://<пользователь>.github.io/<репозиторий>/`.

Имя репозитория `code-sandbox` задаётся отдельно: **Settings** → **General** → **Repository name**. После переименования адрес Pages сменится вместе с именем, а старый адрес начнёт перенаправлять.
