# Code Sandbox

Однофайловая онлайн-песочница. Весь интерфейс — это `index.html`: страница, стили и логика. Редактор тёмный, остальной сайт — светлый, в тёплых оранжевых тонах.

Одно поле принимает любой код сразу: HTML вместе с `<style>` и `<script>`, а также цельный CSS, JavaScript, JSON, SVG, XML или Markdown. Над редактором полоска и проценты показывают, сколько в тексте HTML, CSS, JS, JSON, SVG, XML, Markdown и обычного текста. Предпросмотр собирается в `iframe` с атрибутом `sandbox="allow-scripts"`. У фрейма нет доступа к родительской странице. Родительский скрипт не вызывает `eval`.

## Как открыть

- Локально: откройте `index.html` в браузере или запустите любой статический сервер в корне репозитория.
- В интернете: https://evsey67018.github.io/CODE-SANDBOX/

На странице `file://` буфер обмена и `localStorage` в части браузеров ограничены. Для черновиков и кнопки «Поделиться» удобнее локальный сервер или Pages.

## Как пользоваться

1. Пишите или вставляйте код в единственное поле. Tab вставляет два пробела, Enter сохраняет отступ. Подсветка сама различает смешанный HTML (стили как CSS, скрипты как JavaScript) и цельный JSON, Markdown, SVG или XML.
2. Проценты над редактором обновляются по мере набора.
3. Предпросмотр обновляется сам через секунду. Кнопка **Запустить** или **Обновить** делает это сразу. Смешанный HTML собирается в одну страницу. Чистый JSON показывается в `<pre>` и не выполняется. Markdown превращается в заголовки, списки, жирный, курсив, код и ссылки. SVG и XML рисуются как разметка.
4. Внизу предпросмотра — консоль: `console.log`, предупреждения и ошибки выполнения приходят из фрейма через `postMessage`.
5. **Копировать весь код** копирует текст редактора как есть.
6. **Скачать** сохраняет собранный документ как `sandbox-ГГГГ-ММ-ДД.html`.
7. **Форматировать** и **Сжать** обрабатывают текущий текст.
8. **На весь экран** открывает предпросмотр поверх страницы. Закрытие — Esc или «Закрыть». У полноэкранного окна своя кнопка «Запустить».
9. **Поделиться** записывает текст редактора в хеш `#code=` (base64) и копирует ссылку. Старые ссылки тоже открываются: и одна строка кода, и прежний JSON со вкладками (вкладки склеиваются в один текст).
10. Черновик сам пишется в `localStorage` под ключом `code_sandbox_draft` (пауза 1 секунда) как одна строка. Старый черновик с отдельными вкладками при открытии склеивается. Ссылка из адреса важнее черновика. **Сбросить черновик** возвращает пример «Привет, мир».
11. **Очистить** спрашивает «Вы уверены?» и стирает редактор вместе с предпросмотром.
12. Меню **Примеры** подставляет один фрагмент: приветствие, живую кнопку, калькулятор, JSON, SVG или Markdown.
13. В редактор нельзя записать больше 100 КБ: лишнее не принимается, появляется предупреждение.

Ссылки в Markdown разрешены для `http`, `https` и `mailto`.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Ctrl+Enter или Cmd+Enter | Запустить предпросмотр |
| Ctrl+Shift+C | Копировать код |
| Ctrl+S | Скачать HTML (окно сохранения браузера не открывается) |
| Tab | Вставить два пробела или сдвинуть выделенные строки |
| Shift+Tab | Убрать отступ |
| Esc | Закрыть полноэкранный режим или диалог |

## GitHub Pages

Файл `index.html` лежит в корне `main`. Включить сайт может только владелец репозитория: токен автоматизации не имеет права создавать Pages (`Resource not accessible by integration`).

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В **Build and deployment** выберите **GitHub Actions** и сохраните. В репозитории уже есть `.github/workflows/pages.yml`: он выкладывает корень репозитория. После включения источника перезапустите workflow **Deploy GitHub Pages**.
3. Либо выберите **Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Сайт открывается по адресу https://evsey67018.github.io/CODE-SANDBOX/ . Репозиторий: https://github.com/evsey67018/CODE-SANDBOX .

Имя репозитория `code-sandbox` задаётся отдельно: **Settings** → **General** → **Repository name**.
